Job Title: Senior Machine Learning Engineer (AI & MLOps)
Location: San Francisco, CA / Hybrid
Department: Applied AI & Intelligent Systems

About the Role:
We are seeking an experienced and visionary Senior Machine Learning Engineer to design, scale, and operationalize high-performance AI and deep learning systems. You will bridge the gap between cutting-edge machine learning research and enterprise-scale production services.

Key Responsibilities:
- Architect, train, evaluate, and deploy scalable Deep Learning and Natural Language Processing (NLP) models.
- Develop and optimize LLM pipelines utilizing Retrieval-Augmented Generation (RAG) and prompt engineering.
- Implement robust MLOps pipelines for continuous training, automated testing, and model monitoring.
- Build resilient real-time streaming and data ingestion architectures using Apache Kafka and Apache Spark.
- Containerize machine learning services with Docker and orchestrate distributed deployments on Kubernetes (k8s).
- Maintain and deploy production infrastructure on AWS (SageMaker, S3, EC2) and Google Cloud Platform (GCP).
- Design and integrate high-throughput REST APIs using FastAPI / Python.
- Collaborate with database engineers on PostgreSQL schema design and vector database indexing.

Required Technical Qualifications:
- Advanced proficiency in Python, Data Structures & Algorithms, and System Design.
- 4+ years of hands-on experience with PyTorch, TensorFlow, and Scikit-Learn.
- Strong domain expertise in Natural Language Processing (NLP), Deep Learning, and Large Language Models (LLMs).
- Production experience with Docker, Kubernetes, and automated CI/CD deployment pipelines.
- Hands-on experience with cloud platforms, specifically AWS and GCP.
- Familiarity with distributed big data processing using Apache Spark and Apache Kafka.
- Proficiency in relational databases including SQL and PostgreSQL.
- Solid understanding of Git version control and Linux environments.
