# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The safety and security of users and their sensitive uploaded resume documents is of paramount importance.

If you discover a security vulnerability or sensitive data handling issue within this project, please report it responsibly:

1. **Do not disclose publicly:** Please refrain from opening public GitHub issues for security vulnerabilities.
2. **Contact maintainers:** Send a detailed report to the repository owner or submit a private security advisory on GitHub.
3. **Include details:**
   - Detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Potential impact on users or systems.

### Response Timeline
- We will acknowledge receipt of the report within 48 hours.
- A fix or mitigation will be developed and released promptly in an updated release.
